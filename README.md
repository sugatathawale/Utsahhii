# Utsaahi Yoga & Wellness

Minimalist marketing site for [Utsaahi Yoga & Wellness](https://www.instagram.com/utsaahiyoga_wellness/) — feminine yoga expert, online classes, Nagpur studio & retreats.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Brand colours (from Instagram logo)

| Token | Hex | Use |
|-------|-----|-----|
| Forest | `#084138` | Primary (from Instagram logo) |
| Gold | `#C9B896` | Accent |
| Ivory | `#EDE4D4` | Soft text on green |
| Sage mist | `#E6ECE8` | Soft backgrounds |
